# Explore Karakuram

Public travel website for Explore Karakuram, built with Next.js and ready for
Vercel.

## Prerequisites

- Node.js 20 or newer

## Quick Start

```bash
npm install
npm run dev
npm run build
```

## Deploy to Vercel

Import this repository in Vercel or run the Vercel CLI from the project root.
The framework preset is Next.js and no platform-specific environment variables
are required.

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: verify the production Next.js build
- `npm test`: run the production build check
